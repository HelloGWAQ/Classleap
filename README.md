# classleap

classleap 是由AI编写的一个面向大学生的简单 Windows 桌面工具，用于按周查看各科目是否需要上课，也可用于提示其他周级事项。

## 功能特性

- 按“科目 × 星期”显示周课表
- 单击格子切换“上课 / 不上课”状态
- 根据第一周周一的日期自动生成 18 周日期
- 支持通过 `config.txt` 配置科目和起始日期
- 通过 `save.txt` 保存每周上课状态

## 系统要求

- Windows 10 或 Windows 11

## 安装

1. 下载 `classleap.zip`。
2. 解压到合适的文件夹，完成安装。

## 配置

1. 打开应用安装目录。
2. 用文本编辑器打开 `config.txt`，根据其中提示填写科目及第一周周一的日期。
   - 第一周从周一开始。
   - 程序会自动补全后续 17 周，共 18 周。
   - 2 月按 28 天计算，不考虑闰年。
3. 添加您的课程或任务
4. 保存并关闭 `config.txt`。

## 使用

1. 双击 `classleap.exe` 启动主程序。
2. 主界面表格中：
   - 纵向为科目；
   - 横向为星期。
3. 单击某个格子可切换状态：
   - 绿色：上课；
   - 浅灰色：不上课。
4. 设置完 18 周各科目状态后，按 `Ctrl+S` 保存。
   > 重要：退出程序前请务必保存，否则下次启动时需要重新设置。

## 数据文件

- `config.txt`：科目列表和第一周周一日期。
- `save.txt`：各周各科目的上课状态。

## 删除科目

建议先备份 `config.txt` 和 `save.txt`，然后：

1. 打开 `config.txt`，删除对应科目的行。
2. 打开 `save.txt`，删除对应行的数据。
3. 保存并关闭两个文件。
4. 重新启动 `classleap.exe`。

> **注意**：两个文件中的行必须一一对应。删除时请确认行号一致，避免数据错位。

## 常见问题

**Q：为什么日期不对？**  
A：请检查 `config.txt` 中第一周周一日期是否正确。程序按 2 月 28 天计算，跨闰年时可能需要手动调整。
